# Badge

One or two words of status or category beside a record. Tone carries meaning; never decorative.

- `success` paid, active, done · `warning` pending, due soon · `danger` overdue, failed · `brand` new, in progress · `neutral` draft, archived.
- Add `dot` in dense tables so status reads at a glance; the word still carries the meaning (never colour alone).
- Sentence case, no punctuation. Keep the same word for the same state everywhere in the product.
