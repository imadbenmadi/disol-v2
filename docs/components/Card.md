# Card

The default container for a block of related content on `bg`: a form section, a chart, a list.

- Consumer provides `title`, optional `subtitle`, `actions` (small secondary/ghost Buttons), `footer` (form buttons, right-aligned), and children.
- `flush` removes body padding so a DataTable or list runs edge to edge.
- Don't nest cards. Inside a card, group with spacing or a `surface-sunken` well.
