# Tag

A lowercase mono label that sets the technical voice: release state, region, counts, categories.

- Consumer provides the text, plus optional `dot` (a live/primary dot) and `tone="accent"`.
- Write it like a CLI flag or path: `open beta / algiers region`, `managed`, `99.9% sla`. Lowercase, slashes for separators, no full stops.
- Use it above hero headlines, as ServiceCard categories and as PricingCard ribbons. For record status in tables, use Badge.
