# PricingCard

A plan in a pricing table: name, price, period, description, CTA and features.

- Consumer provides `name` (lowercase, shown in mono), `price` (pre-formatted), `period`, `description`, `action` (Button `block`), `features`, and `featured` with a `ribbon` for the recommended plan.
- 2–4 plans side by side, featured in the middle. Feature lists are cumulative: start the higher plan with "Everything in Starter, plus".
