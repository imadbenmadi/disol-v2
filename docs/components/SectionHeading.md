# SectionHeading

The headline block of every marketing section: eyebrow Tag, title with an italic serif accent, description, actions and mono footnote.

- Consumer provides `title`, optional `accent` (the last phrase, set in Instrument Serif italic), `eyebrow`, `description`, `actions`, `footnote`, `size` (`xl` hero, `lg` section, `md`), `align`.
- One accent phrase per heading, 1–3 words, always at the end. The rest of the title is Geist.
- Arabic: the accent becomes the same face in `primary`. There is no Arabic serif pairing.
- Write `footnote` in label-mono style: `free consultation / reply within one business day`.
